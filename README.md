# FMODSandbox

## Setup Instructions

<details>
  <summary>Expand to read more</summary>
  
  **Prerequisites**
  * [FMOD Engine](https://www.fmod.com/download) (I used v2.02.12)
  * [Visual Studio](https://visualstudio.microsoft.com/downloads/) (I used v18.9.2; Aug 2026)
  
  **Optional Extras**
  * [FMOD Studio](https://www.fmod.com/download) (I used v2.02.12)
  
  **Steps**
  * Clone the repo to a sensible location.
  * In the root dir of the cloned repro, create a folder called "FMOD_API".
  * From your install of FMOD Engine, copy the `...\api\core` and `...\api\studio` folders into your created `FMOD_API` folder.
  * Run the app!
</details>

## Keyboard Controls

<details>
  <summary>Expand to read more</summary>
  
  * `ArrowUp/ArrowDown` - Change selected item
  * `ArrowLeft/ArrowRight` - Change item value
  * `Tab` - Change selected section
  * `Spacebar` - Play explosion sound
  * `ESC` - Quit
</details>
